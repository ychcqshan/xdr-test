# 资产列表

> **路由:** `/assets`
> **模块:** 资产管理
> **组件:** `AssetListView.vue`

## 概述
资产全量库是所有受控终端的实时清单看板。安全管理员在此页面搜索、筛选和监控所有已注册的终端资产，并可点击任意行进入资产详情页。

## 布局

### 搜索区 (顶部 Glass Card)
- 页面标题："资产全量库"
- 副标题："所有受控端点与云端资产的实时清单看板"
- 行内搜索表单

### 资产表格 (Bento Card)
- 表头：指示灯 + 标题 + 资产总数徽章
- 数据表格 + 分页器

## 搜索/筛选字段

| 字段 | 类型 | 必填 | 选项/枚举 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|:---|
| 资产身份 | 文本输入 | 否 | — | 空 | 模糊搜索主机名 / IP / Agent ID |
| 操作系统 | 下拉选择 | 否 | WINDOWS, LINUX, KYLIN, UOS | 全部 | 按 OS 类型筛选 |
| 在线状态 | 下拉选择 | 否 | ONLINE, OFFLINE | 全部 | 按实时状态筛选 |
| 所属单位 | 文本输入 | 否 | — | 空 | 按组织单位筛选 |
| 责任人 | 文本输入 | 否 | — | 空 | 按负责人姓名筛选 |

## 表格列

| 列名 | 字段 | 格式 | 宽度 | 说明 |
|:---|:---|:---|:---|:---|
| 受控端点名称 | hostname | 文本 + Popover | 自适应 | hover 弹出 Agent ID / OS 版本 / IP / MAC |
| 所属单位 | unitLevel1 | 文本 | 140px | 一级组织单位 |
| 责任人 | responsiblePerson | 文本 | 100px | 资产负责人 |
| 局域网地址 | ipAddress | 等宽字体 | 160px | 内网 IP |
| 实时状态 | status | 状态标签 | 120px | ONLINE=在线(绿) / OFFLINE=离线(灰) |
| 安全评分 | riskScore | 进度条+数值 | 180px | 0-100%，\>70 红 / >40 橙 / ≤40 绿 |
| 最后在线心跳 | lastHeartbeat | 时间 | 180px | 仅显示时间部分 |

## 交互

### 页面加载
- 自动调用 `getAssets({page:1, size:15})`，loading 状态

### 搜索
- **触发**: 点击"执行查询"按钮
- **行为**: 以当前筛选条件 + 分页参数请求后端
- **分页**: 切换页码或每页条数时自动重新查询

### 查看详情
- **触发**: 点击表格任意行 (`@row-click`)
- **行为**: 跳转 `/assets/:id?agentId=xxx`

### Popover 预览
- **触发**: hover 主机名
- **内容**: Agent ID、OS 版本、内网 IP、物理 MAC

## API 依赖

| API | 方法 | 路径 | 触发 | 参数 | 备注 |
|:---|:---|:---|:---|:---|:---|
| 资产列表 | GET | `/api/v1/assets` | 加载/搜索/翻页 | page, size, keyword, osType, status, unitLevel1, responsiblePerson | 分页返回 |

## 页面关系
- **流入**: 侧边栏导航"资产管理"
- **流出**: → 资产详情 (`/assets/:id`，携带 agentId query)
