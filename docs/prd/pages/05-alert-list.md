# 威胁告警

> **路由:** `/alerts`
> **模块:** 威胁管理
> **组件:** `AlertListView.vue`

## 概述
威胁告警页面展示所有安全检测事件和告警信息。安全运维人员在此查看、筛选和处置告警，进行事件响应。

## 核心功能
- 告警列表展示（标题、严重程度、检测时间）
- 告警详情查看
- 告警状态变更（响应处置）
- 告警统计

## 严重程度枚举

| 值 | 显示 | 颜色 |
|:---|:---|:---|
| CRITICAL | 紧急 | 红色 `#EF4444` |
| HIGH | 高危 | 红色背景 |
| MEDIUM | 中危 | 橙色 `#F59E0B` |
| LOW | 低危 | 灰色 `#64748B` |

## API 依赖

| API | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|
| 告警列表 | GET | `/api/v1/alerts` | 分页查询，`page + size` |
| 告警详情 | GET | `/api/v1/alerts/:id` | 单条告警详细信息 |
| 更新状态 | PUT | `/api/v1/alerts/:id/status` | 变更告警处置状态 |
| 响应处置 | POST | `/api/v1/alerts/:id/respond` | 标记已响应，`operator` 参数 |
| 告警统计 | GET | `/api/v1/alerts/stats` | 返回 new / total 统计 |

## 页面关系
- **流入**: Dashboard "管理情报详情" 按钮 / 侧边栏
- **流出**: 无（独立页面）
