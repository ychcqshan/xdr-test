# 安全概览 (Dashboard)

> **路由:** `/dashboard`
> **模块:** 安全态势感知
> **组件:** `DashboardView.vue`

## 概述
安全概览是 XDR 平台的首页，提供全局安全态势的一站式可视化。安全运维人员登录后首先看到此页面，快速掌握当前资产状态、威胁水位和合规健康度。

## 布局

### Hero 统计区 (顶部 Mesh 背景)
4 个浮动玻璃卡片横向排列，每卡包含：图标、统计标签、数值、趋势百分比

### Bento Grid 区域 (下方)
- **全球威胁趋势** (占 3 列 2 行)：折线图 + 7D/30D 时间切换
- **风险等级分布** (占 1 列 1 行)：环形饼图
- **合规健康度** (占 1 列 1 行)：仪表盘进度环
- **优先处置任务流** (占 4 列 1 行)：最新告警表格

## 数据卡片

| 卡片 | 数据来源 | 指标含义 |
|:---|:---|:---|
| 资产总数 | `GET /assets/stats → total` | 所有已注册终端数量 |
| 在线防御 | `GET /assets/stats → online` | 当前心跳活跃的终端数 |
| 待处理威胁 | `GET /alerts/stats → new` | 未处理的告警数量 |
| 情报事件流 | `GET /alerts/stats → total` | 累计安全事件总数 |

## 交互

### 页面加载
- 并发调用 `getAssetStats()` + `getAlertStats()` + `getAlerts({page:1, size:5})`
- 初始化 ECharts 图表（自动响应窗口 resize）

### 导航
- 点击"管理情报详情"按钮 → 跳转 `/threat/alerts`（告警列表页）

## API 依赖

| API | 方法 | 路径 | 触发 | 备注 |
|:---|:---|:---|:---|:---|
| 资产统计 | GET | `/api/v1/assets/stats` | 页面加载 | 返回 total, online |
| 告警统计 | GET | `/api/v1/alerts/stats` | 页面加载 | 返回 new, total |
| 最近告警 | GET | `/api/v1/alerts?page=1&size=5` | 页面加载 | 分页返回，显示前 5 条 |

## 页面关系
- **流入**: 登录成功后默认跳转
- **流出**: → 告警列表 (`/alerts`)
- **数据耦合**: 资产统计、告警统计均为只读展示
