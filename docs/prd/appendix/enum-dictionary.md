# 枚举字典

## 操作系统类型 (osType)

| 值 | 显示名 | 来源 |
|:---|:---|:---|
| `WINDOWS` | Windows | AssetListView 搜索选项 |
| `LINUX` | Linux | AssetListView 搜索选项 |
| `KYLIN` | 麒麟 (Kylin) | AssetListView 搜索选项 |
| `UOS` | 统信 (UOS) | AssetListView 搜索选项 |

## 在线状态 (status)

| 值 | 显示名 | 颜色样式 |
|:---|:---|:---|
| `ONLINE` | 在线 | 绿色 `#065F46` / 背景 `#ECFDF5` |
| `OFFLINE` | 离线 | 灰色 `#64748B` / 背景 `#F1F5F9` |

## 告警严重程度 (level)

| 值 | 中文 | 颜色 | CSS 类 |
|:---|:---|:---|:---|
| `CRITICAL` | 紧急 | `#EF4444` (红) | `.critical` |
| `HIGH` | 高危 | `#EF4444` (红) | `.high` |
| `MEDIUM` | 中危 | `#F59E0B` (橙) | `.medium` |
| `LOW` | 低危 | `#64748B` (灰) | `.low` |

## 安全评分风险等级 (riskScore)

| 评分范围 | 等级 | 颜色 |
|:---|:---|:---|
| > 70% | 高风险 | `#EF4444` (红) |
| 41-70% | 中风险 | `#F59E0B` (橙) |
| ≤ 40% | 低风险 | `#10B981` (绿) |

## 统计卡片趋势 (trend)

| 方向 | 含义 | 显示 |
|:---|:---|:---|
| `> 0` | 上升 | 绿色 ▲ + 百分比 |
| `< 0` | 下降 | 红色 ▼ + 百分比 |
